## How I use Git carefully
- I run git status and git diff before every commit to confirm exactly what I am about to save.
- I keep each commit focused on one clear idea instead of bundling unrelated changes together.
- I keep secrets and temporary files out of the repository with a .gitignore file.
- I write commit messages that start with a verb and explain why the change matters.
