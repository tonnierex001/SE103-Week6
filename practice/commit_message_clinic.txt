My personal commit message rule:
My rule is to start every commit message with a verb, like add, fix, update, or remove, and then name the specific thing that changed. I write it for a teammate who was not watching me work, so it explains the purpose and not just the files. If I read only the message in three weeks and cannot tell what it was for, I rewrite it before committing.
