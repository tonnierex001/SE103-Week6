What I check before committing:
Before every commit, I run git status to see which branch I am on and which files have changed. I run git diff to read the exact lines I modified, so I do not accidentally include something I did not mean to change. Then I run git diff --staged after adding files, to confirm the staged set matches my intention. If I see anything unexpected, I unstage it or fix it before committing. This habit has already caught small mistakes for me.
